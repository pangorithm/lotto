# 조사 범위와 판단 기준

- 산출물: 프로젝트 루트의 SQLite 파일과 한국어 사용 문서(요청). 대상은 로또 6/45, 연금복권520, 연금복권720+의 공개 회차와 당첨 번호다. 당첨자 신원은 수집하지 않는다.
- 결과 축: 로또 아카이브, 연금복권520 아카이브, 연금복권720+ 아카이브. 전 회차를 우선 목표로 하되 검증하지 못한 범위는 명시한다.
- 변경 축: 추첨기/볼, 공개·방송, 위탁사업자, 상품·규칙, 독립 참관/검증. 실제 효력일·최초 적용 회차·발표일을 구분한다.
- 예정 기준일: 환경의 현재일 2026-11-23. 원천별로 실제 확인한 최신 공개 회차를 별도로 표기한다. 예정 회차는 저장하지 않는다.
- 증거: 결과의 회차별 원천과 변경 이력의 인용 근거를 DB에 직접 연결한다. 발표/검증 이벤트와 실제 절차 변경을 분리한다. 확인된 변경은 확률 변화나 예측력의 증거로 취급하지 않는다.
- 구현: Rust 데몬은 후속 소비자다. 이번 범위는 재현 가능한 DB와 읽기 계약이다.
