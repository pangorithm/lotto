# 추첨·운영 이력 기준 당첨번호 분석

2026-11-23 KST 스냅샷의 [SQLite](../lottery.sqlite3)를 읽기 전용으로 분석했다. [전체 집계 JSON](period-statistics.json)은 각 구간의 시작·종료일과 이력 ID, 로또 번호별 빈도와 홀수 개수 및 직전 회차 중복 분포, 연금복권 자리별 숫자·조별 빈도를 담는다.

## 구간과 검정 기준

- 기본 집계(`dated`)는 첫 적용 회차가 확인된 변경과 날짜를 특정할 수 있는 후보 경계를 모두 쓴다. 구간은 그 회차의 실제 추첨일부터 시작하고 해당 회차를 새 구간에 포함한다. 같은 회차의 변경은 하나의 경계로 묶는다. 근거 상태는 원본을 그대로 유지한다.

| 기본 분석에 추가한 날짜 | 회차 | 경계의 근거 |
|---|---:|---|
| 2003-02-08 | 로또 10회 | SBS 생방송 예고에 날짜가 있어 분석 기준점으로 사용. 정례 생방송 최초 회차라는 뜻은 아님. |
| 2012-01-04 | 연금복권520 27회 | MBN 첫 방송으로 기록된 후보 회차. 당시 첫 편성 자료는 미확인. |
| 2016-12-17 | 로또 733회 | 비너스 RL2 최초 사용 보도. 실제 적용을 독립적으로 확인하지 못함. |

- 로또 10회의 예고를 제외한 일회성 예비 장비 사용·특별 참관은 별도 사례로 두었다. 정례 생방송의 다른 후보인 2003년 10월은 일자와 회차가 없어 임의로 넣지 않았다. 세 경계를 합친 비교는 JSON의 `confirmed`를 사용한다(720+는 추가 경계가 없어 `dated`와 같다). 합친 구간의 중앙값·직전 중복 등은 원래 회차에서 다시 계산한 값이지, 세분 구간의 값을 단순 평균한 것이 아니다.
- 번호 분포 비교는 회차를 통째로 섞는 순열 검정(검정당 9,999회, 시드 `645520720`)이다. 전체 분포와 구간 크기로부터 기대 빈도를 구하고, 실제 구간과의 빈도 차이 제곱을 기대 빈도로 나눠 더한 값을 비교했다. 로또 한 회차의 비복원 추출과 520의 한 회차 1등 두 결과의 묶음을 유지한다. 로또 본번호·보너스는 따로, 연금복권은 1등의 조와 각 자리 빈도를 함께, 720+ 보너스는 별도로 비교했다. 결과는 시간 추세나 연속 의존이 없는 교환 가능성을 귀무가설로 삼으며, 시간 의존 자체나 추첨 번호의 모든 결합 패턴을 검정한 것은 아니다.
- 전체 15개 검정에 Holm 보정을 적용했다. 가장 작은 보정 전 p값은 날짜 기준 10개 구간의 로또 본번호 비교에서 나온 0.0923이었다. 보정 전후 모두 0.05 미만인 비교가 없었다. 이는 **검정한 분포 차이를 발견하지 못했다**는 뜻이지, 모든 방식의 확률이 같다는 증명은 아니다.
- **물리적 교체의 효과와 운영 효과를 분리할 수 없다.** 예를 들어 로또 262회는 추첨기와 수탁자가 같이 바뀌고, 836회는 수탁자·방송사·판매채널이 동시에 바뀌었다. 520→720+도 추첨기만 바뀐 것이 아니라 조의 범위, 번호 범위, 등위 체계, 추첨 구조가 바뀌었다. 구간별 패턴은 사후 관측치이지 예측 모델 입력의 타당성을 입증한 것이 아니다.

## 로또 6/45: 1,251회

판매액은 명목 원화, 판매 게임 수는 그 회차의 가격으로 판매액을 나눈 값이다. 1등은 개인 수가 아닌 당첨 게임 수다. `중앙값`은 1등이 나온 회차만 대상으로 한, 게임당 상금의 중앙값이다. `연번`은 본번호 중 적어도 한 쌍이 연속 정수인 회차의 비율이고, `직전 중복`은 같은 구간 안에 속한 인접 두 회차 본번호의 교집합 크기 평균이다.

- 가격 인하 전을 1–87회로 합쳐 88–261회와 비교하면, 평균 판매액은 679.0→489.9억원으로 감소했지만 **판매 게임 수는 3,395만→4,899만**으로 증가했다. 1등 게임 수가 3.84→6.04로 변한 것을 번호 분포나 회차당 확률의 변화로 해석할 수는 없다. 1등 미배출 14회 중 11회가 최초 87회에 집중됐다.
- 균등 비복원 추출에서 본번호 합계의 기대값은 **138**, 연번의 확률은 **52.87%**, 독립인 직전 추첨과 겹칠 번호 수의 기대값은 **0.80개**다. 1–9회 구간은 평균 합계 152.56과 직전 중복 1.38개로 다른 구간보다 높았지만, 각각 9회와 8쌍을 관측한 값이다. 1–9회와 10–87회의 본번호 빈도 비교에서도 뚜렷한 차이는 검출되지 않았다(보정 전 p=0.1422). 합계·중복 자체를 따로 검정한 것은 아니다.
- 전 기간 본번호에서 34번이 188회, 9번이 137회였다. 각 번호의 균등 기대 빈도는 166.8회(`1,251×6/45`)이다. 45개 중 최댓값과 최솟값을 사후에 고른 것이므로, 이를 특정 번호 편향이나 추천의 근거로 쓰지 않는다.
- RL2 보도를 기준으로 나눈 575–732회와 733–835회의 본번호 평균 합계는 각각 134.78과 138.50, 연번 비율은 58.2%와 56.3%였다. 이 두 구간의 번호별 분포 차이는 뚜렷하지 않았다(보정 전 p=0.2904).
- 예비 장비 보도가 있는 461회·636회와 확대 참관 1,071회·1,147회 번호도 JSON의 `one_off`에 남겼다. 한 회차로 해당 방식의 번호 분포를 추정하지 않았다.

## 연금복권520: 461회

회차마다 1등 번호 2개를 관측했다. `중복 숫자`는 한 1등 번호의 여섯 자리 안에 같은 숫자가 두 번 이상 있는 비율이다. `같은 조`는 한 회차의 1등 두 번호의 조가 서로 같은 회차 수다. 2등과 하위 등위를 1등과 합쳐 독립 추첨 표본으로 세지 않았다.

## 연금복권720+: 342회

회차마다 1등과 보너스는 각각 한 결과다. 2–7등에 적힌 번호는 1등 번호에서 파생되므로 따로 세지 않았다.

같은 수탁자의 계약이 갱신된 두 구간에서 1등 조·자리 또는 보너스 자리 분포 차이는 검출되지 않았다. 520과 720+는 조 범위와 번호 범위가 달라 두 데이터를 하나의 분포로 비교하지 않았다.

## 번호 생성 데몬에 반영할 점

이력은 통계 조회와 시간순 검증의 구간 라벨로 사용하고, 이번 결과만으로 번호 가중치를 바꾸지 않는다. 나중에 이력 기반 생성기를 시험할 경우, 당시까지 알려진 이력만 입력으로 사용하고 이후 회차에서 균등 무작위 생성기와 같은 조건으로 비교한다. 특히 로또 1등 당첨 게임 수는 판매량과 구매자의 선택이 반영된 수치이므로, 추첨 번호 예측력의 대리지표로 쓰지 않는다.

## 재현

```sh
uv run scripts/analyze_periods.py > period-statistics.rebuilt.json
```

계산에 사용한 NumPy 버전과 입력 DB SHA-256은 JSON 헤더에 있다. 당첨 기록의 출처와 신뢰도는 [원본 검증 기록](verification.md), 변경 이력의 출처와 유효 범위는 [이력 데이터](../data/events.sql)를 참조한다.
